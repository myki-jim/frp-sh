# About the Name: Not That FRP

**Yes, you read it right**: the domain is `frp.sh`, and it has **nothing** to do with [fatedier/frp](https://github.com/fatedier/frp).

> It's like registering `apple.com` and then deciding not to sell fruit — pure "domain squatting", and we did it anyway.

## Why frp.sh?

Because of what we actually believe in:

- **F**ast Room Protocol
- **R**eal-time P2P
- **P**layful Shell

`frp.sh` is a **social P2P networking tool**: `create` a room, `join` with a code — spin up a virtual LAN like starting a game lobby.

**We don't penetrate your NAT. We delete the concept of NAT.**
