# 名字的由来：不是你想的那个 FRP

**没错，你发现了**：这个域名叫 `frp.sh`，但它跟 [fatedier/frp](https://github.com/fatedier/frp) 没有半毛钱关系。

> 这就像注册了 `apple.com` 但决定不卖水果 —— 纯属“域名碰瓷”，但我们就这么干了。

## 那为什么叫 frp.sh？

因为我们的核心理念是：

- **F**ast Room Protocol（极速房间协议）
- **R**eal-time P2P（实时点对点）
- **P**layful Shell（好玩的命令行）

`frp.sh` 是一套**社交化的 P2P 组网工具**：`create` 建房间、`join` 凭号加入，像开黑一样拉起一个虚拟局域网。

**我们不穿透内网，我们消灭内网的概念。**
