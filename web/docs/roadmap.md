# 路线图

当前版本聚焦「简单、健壮、够用」。以下按优先级列出计划中的能力。

## 近期

- [ ] **并发多连接复用**：同一隧道同时承载多条本地 TCP 连接（当前为顺序复用）
- [ ] **WebSocket 实时信令**：房主即时感知访客加入，替代轮询（降低直连建立延迟）
- [ ] **UPnP 自动端口映射**：打洞前的补充手段，路由器支持时直接映射端口

## 中期

- [ ] **x25519 密钥交换**：免口令自动协商会话密钥（替代手工 `--key`）
- [ ] **中继通道加密**：中继路径同样提供机密性（当前 `--key` 仅作用于 P2P 直连）
- [ ] **多节点房间（>2 人）**：中心节点广播成员地址，网状 P2P
- [ ] **传输参数自适应**：根据丢包/时延自动调整窗口、重传间隔、MTU

## 远期

- [ ] **平台化**：Windows/macOS 安装包、开机自启、托盘图标
- [ ] **中继集群**：多服务器中继池 + 就近选路
- [ ] **兼容层**：接入现有协议生态（可选）

## 已实现的能力（v0.1）

-  房间制信令（REST + UDP 探测 + TTL 过期）
-  UDP 打洞（PUNCH/ACK 同时握手 + 端口散布）
-  FRS1 可靠流（滑动窗口 + 重传 + keepalive + FIN 握手）
-  ChaCha20-Poly1305 端到端加密（`--key`）
-  顺序多连接复用（`--max-conns`）
-  TCP 中继回退（配对 + 双向拷贝 + 迟到直连复查）
-  断线自动重连（指数退避 + 刷新公网地址 + 房间刷新）
-  同局域网自动直连（通告局域网地址，双路打洞）
-  组网模式（`lan` 系列：虚拟网卡整机入网，10.66.0.0/24；访客可访问房主局域网）
-  设备唯一 ID（UUID）+ 稳定派生虚拟 IP + 房主 IP 池（`--guest-ips`）
-  服务端密码认证（`serve --password`：请求 401 校验 + 中继认证）
-  中继流量加密（ChaCha20-Poly1305 流加密，防嗅探）
-  版本治理：协议版本冲突控制（`/version`）、启动更新检查（可跳过/代差强制）、服务器/房主版本黄红提示
-  局域网接入默认不暴露（`--expose-lan` 显式开启）
-  Windows 兼容（ICMP 毒化处理、TUN/WinTun、自动 UAC 提权、防火墙自动放行）
-  macOS utun 兼容（点对点路由修复）
-  CLI 全英文 + 彩色输出 + ASCII 标识 + 交互式安装初始化
-  端到端测试与真实 NAT 实测
