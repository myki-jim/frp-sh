# 路线图

## 0.6.0 已具备

- 键盘交互终端应用、Profile、个人房间预设和邀请。
- 默认 LAN，Game/Dev 参数预设，以及显式 TCP/UDP 服务发布。
- 有每成员和每房间并发上限的服务多路复用。
- 安装阶段配置特权辅助服务，日常房间操作使用普通账户。
- 独立日志页、日志文件和 CLI 查询。
- 可配置的服务端房间、登记成员容量限制。
- SQLite 永久空间、设备身份、15 分钟短期邀请和成员加密中继。
- Windows SCM、Linux systemd、macOS LaunchDaemon 原生后台监督入口。
- DNS 所有权验证、自定义域名 HTTP 发布和 18443 按需 HTTPS 证书。

Web Panel 已在 0.4.0 移除，终端宠物已在 0.5.3 移除。

## 后续方向

- 并发加入、重连和中继负载下的容量压测。
- 自适应轮询或事件通知，降低信令开销。
- 中继带宽公平分配、限速和流量预算统计。
- 在将配额作为实时在线人数之前，完善离开与成员过期语义。
- 扩大真机和网络测试覆盖，包括 OpenWrt。
- 每域名带宽预算、速率限制、WebSocket 与路径路由。

以上为开发方向，不代表已经实现或承诺交付日期。
