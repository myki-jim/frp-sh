# 版本策略

当前发布版本为 **0.5.4**，信令协议 **v3**，辅助服务协议 **v2**。项目仍处于 0.x 开发阶段；协议不兼容的变更需要同步升级。

使用 `frp-sh --version` 查看客户端版本，使用 `GET /version` 查看服务器版本。协议版本不同会拒绝连接；程序版本不同但协议相同时可以兼容，并显示提示。

## 更新

显式运行 `frp-sh update` 检查更新并显示安装说明。正常启动不自动检查或安装更新。重新运行安装器可同时升级客户端和辅助服务；安装维护阶段可能需要管理员授权，日常房间操作使用普通账户。

服务端应单独部署完整 Release 资产。固定版本、保留备份并阅读发布说明；服务端重启会清空内存中的房间注册表。

## 0.5.4

新增 `--max-rooms`、`--max-members`、`--max-total-members` 服务端容量参数。旧版 0.5.3 不识别这些参数；本次属于兼容新增，信令协议仍为 v3。
