# 0.4.0 开发分支验证记录

基线：`e1037af9b4d5c37b0cf7613b88a0c08d70c00ff0`。开发分支：`codex/0.4.0-overhaul`。本记录不表示已发布 v0.4.0。

## 已实现

- 删除客户端和服务端 Web Panel、管理数据接口、日志缓冲和流量上报。凭据仅通过请求头认证，不再接受 URL token。
- 安装系统辅助服务，客户端普通账户通过版本化本地 IPC 创建和使用虚拟网卡。限制用户身份、设备角色、私有 IPv4 路由、请求大小、队列和超时；拒绝任意命令和路径。
- Windows 仅授予安装账户必要的管道读写与服务进程身份查询权限；Linux/macOS 验证 Unix socket 对端 UID。
- STUN 与自建 UDP 探测并发；强制 TCP 路径跳过公网探测及无用 TURN 分配；版本查询缓存、重连抖动及认证错误分类。
- 中英文选项、轻量连接状态行、ASCII 纯文本和 JSON 模式。日志独立异步写入每进程 JSONL，单文件 5 MiB，三份轮转；清理跳过存活进程。总容量限制为清理目标，多进程同时活跃时允许超过 64 MiB。
- 默认安装精简客户端；完整服务端、精简客户端及辅助服务分别打包，配套 SHA-256 文件。安装器锁定同一 Release 标签，Windows 校验 Wintun 签名。校验和不等同独立发布签名。

## 地址探测采样

命令：`cargo test --locked --test discovery_benchmark -- --ignored --nocapture`。

Windows 本机回环网络，每组 30 次，全部成功。基线复现旧版本的串行 STUN → UDP echo 算法，使用相同 STUN 实现；新算法并发发送。STUN 不响应由本地持有但不回复的 UDP socket 模拟。

| 场景 | 旧算法 p50 / p95（ms） | 新算法 p50 / p95（ms） |
| --- | ---: | ---: |
| 仅 UDP echo | 0.0997 / 0.1550 | 0.1051 / 0.1782 |
| STUN 不响应、echo 可用 | 3239.6516 / 3248.8648 | 0.1669 / 0.3109 |

结果只适用于地址探测阶段。公网完整建链、重连和高吞吐 LAN IPC 的 p50/p95 尚待受控环境验证，不能据此宣称任意网络秒连。
