# frp-sh 0.4.1

修复 0.4.0 LAN 中继会话反复断线、重建虚拟网卡的问题。房主和访客均应重新运行安装器升级。

- 访客在数据通道内回复网格心跳，不再把 `FRPING` / `FRPONG` 当作 IP 包交给网络辅助服务，避免辅助服务拒绝无效数据后断线。
- 直连打洞次数耗尽不再跳过已通告的 TURN 中继，避免房主与访客选择不同的回退路径。
- 房主在某个访客的 TURN 路径不可用时进入 TCP 回退，避免重复等待同一条不可用的 TURN 路径。
- 已停止直连探测的访客不会在 TCP 中继建连后再次等待直连复查。
- 访客终端显示传输或辅助服务断开的具体错误，便于区分网络问题与设备问题。
- 包含 Windows PowerShell 5.1 安装器校验文件读取及中文编码修复。

协议仍为 v2。服务器 0.4.0 保持协议兼容；仅更新服务器不能修复旧客户端的心跳处理。

新增回归覆盖控制帧与网卡数据隔离、加密网格多轮心跳与 RTT、辅助服务断开错误。实际跨公网 Windows/macOS 使用体验仍需双方升级后验证。
