# frp-sh 0.5.2

- Adds 20 complete ASCII companion looks: five body silhouettes and four equipment rigs. Open the wardrobe with P or `frp-sh pet`; choose, save, hide and reduce motion without restarting a room.
- Companions use a reserved compact footer or detailed sidebar, never covering device cards. Small windows hide the dock. Settings persist locally and remain separate from room presets and saved connections.
- Existing connection evidence drives waiting, connecting, direct, relay, instability and reconnecting feedback. Quality transitions are debounced; relay is treated as a normal transport. Service rooms use explicit lifecycle state. No extra network probes or pet data are transmitted.
- Includes the Windows installer manifest fix for architecture names containing underscores, covered by the actual release manifest regression.

Protocol v3 and helper protocol v2 are unchanged. Companions are optional and can be disabled. There is no plugin runtime, cloud account or collectible marketplace.
