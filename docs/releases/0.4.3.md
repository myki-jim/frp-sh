# frp-sh 0.4.3

交互式连接终端改为全屏房间与设备卡片面板。

- 深色界面、薄荷色重点信息、独立设备卡片；突出房间号、设备名、角色、虚拟 IP、连接方式及已测量的延迟。
- 房主与访客均定期刷新完整房间成员列表；本机单独标记，未知链路不会伪造延迟。房间成员记录不等同于已建立连接，访客不会把其他成员显示成自己的直连。
- 自适应终端尺寸，中英文名称按实际显示宽度截断；方向键翻页，L 切换语言，Q / Esc / Ctrl+C 退出。
- 状态变化局部重绘，退出或错误后恢复原屏幕、光标与输入模式。
- 正常连接界面不显示网卡配置、UUID、公网地址和诊断流水；诊断进入独立日志文件，仍可通过 `frp-sh logs` 查看。`--plain` / `--json` 保持适用于脚本的文本输出。
- 默认不通告本地子网；修复公网地址刷新时绕过 `--expose-lan` 设置的问题。明确开启共享的连接配置仍保留其设置。
- 修复按设备名登记、按 UUID 清理链路导致的陈旧状态显示。

协议仍为 v2，兼容 0.4.2 服务端。安装器同时更新客户端和辅助服务。

验证包含多成员双角色模型、中英文窄屏与分页、终端控制字符隔离、真实 Windows 终端语言切换与退出恢复，以及连接与安全回归。
