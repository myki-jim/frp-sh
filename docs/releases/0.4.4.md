# frp-sh 0.4.4

终端应用、房间邀请和重连修复。

- 直接运行 `frp-sh` 或 `frp-sh app` 打开终端应用，提供首页、连接配置、加入房间、设置、帮助和日志页面；`frp-sh profile` 进入配置管理。
- 支持键盘新建、编辑、设置默认和删除 profile，密码与密钥始终隐藏；连接结束或失败后返回首页。
- 房间中按 `I` 复制邀请链接或 Windows / macOS / Linux 一行安装、保存配置并加入的命令。邀请网页默认英文，可切换中文。
- 邀请包含服务器访问凭据及房间密钥，仅供私下分享。数据放在 URL fragment，网页在本地读取，不发送给官网；诊断日志会隐藏邀请。`frp-sh connect <link> --save-only` 可仅保存配置。
- 按 `G` 打开独立日志页；方向键和 PageUp/PageDown 滚动，F 筛选级别，空格暂停，End 回到实时。房间页面不显示日志流水，致命错误也写入日志。
- 旧链路读写任务一起取消，旧连接的关闭事件不再影响同 UUID 的新链路。
- 房主识别设备端点变化并替换旧连接，丢弃迟到的旧中继结果；中继失败重试间隔从 30 秒缩至 1 秒，客户端退避上限降至 4 秒。
- 修复多个访客同时等待 TURN 时只有最后一个得到处理的问题；无 TURN 通告立即进入 TCP 路径；TURN 重分配在后台进行并及时更新通告。
- TUN 数据通道使用双向心跳，在持续 12 秒没有收到对端数据时触发重连，同时保持正常空闲连接。

协议仍为 v2，兼容现有服务端。房主和访客均需更新才能完整获得连接修复。默认不共享本地局域网，既有 CLI 与 `--plain` / `--json` 仍可使用。

验证：跨页面键盘与窄屏测试、邀请注入与凭据隐藏、旧链路替换、空闲连接和无响应超时、同一 UUID 旧 TCP 仍打开时连续三次重新加入，以及完整连接、安全和安装器回归。
