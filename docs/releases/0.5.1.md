# frp-sh 0.5.1

- New `create`, `create game`, and `create dev` entry points all create LAN rooms. A bare numeric room ID joins directly, preserving leading zeros. Existing game/dev service commands remain compatible.
- The terminal app adds one-step creation, custom room forms and personal parameter presets: save, edit, rename, copy, delete and use without overwriting saved defaults. Built-in scenes share safe LAN defaults; they do not auto-publish services. Saved connections remain separate under Profile.
- Presets never store payload passphrases or invitations. Join forms support an optional extra payload passphrase. Q/Esc asks before leaving a room; diagnostic logs remain separate.
- Guest virtual-network heartbeats now update RTT statistics, including encrypted TCP relay links. Missing initial measurements stop displaying an endless measuring state.
- Installers prefer website downloads, with a version-pinned checksum manifest and GitHub fallback. Windows reuses signature-valid installed Wintun drivers.

Signaling protocol v3 and helper protocol v2 are unchanged. No voice, third-party plugin runtime, automatic game discovery or new Internet exit mode is included.
