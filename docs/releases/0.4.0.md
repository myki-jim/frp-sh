# frp-sh 0.4.0

本版本移除 Web Panel，以精简终端和受限网络辅助服务作为主要使用方式。

- 删除客户端、服务端 Web Panel 及相关管理接口和流量上报。
- 安装阶段配置系统网络辅助服务；安装账户日常运行不再重复请求管理员/root 权限。
- 默认安装精简客户端，完整服务端与网络辅助服务分别提供；Windows 两个程序合计实测较旧主程序减少 38.7%，不含 Wintun DLL、配置和备份。
- 并发地址探测、精简强制中继流程、重连抖动及认证错误分类；修复多候选地址下直连路径不一致的问题。
- 提供中文/英文终端、纯文本与 JSON 输出；日志异步写入独立 JSONL 文件并轮转。
- 加固会话加密、重放防护、房间所有者授权和本地辅助服务权限边界。

## 从 0.3.x 升级

重新运行安装器，安装匹配版本的客户端和辅助服务。手动替换客户端不能完成辅助服务安装。现阶段升级维护仍通过安装器授权完成，没有启用免授权自动升级。

原 Web Panel 参数和页面已删除，请改用终端命令。服务端使用 `frp-sh-<平台>`；精简客户端使用 `frp-sh-client-<平台>`，并配套 `frp-sh-net-<平台>`。Windows 仍需 Wintun。每个二进制附有 SHA-256 校验文件。

本版协议版本为 2，建议服务器和所有连接端一并升级。历史中曾提交的测试凭据已从发布历史清理；清理历史不等于撤销凭据，旧凭据应在提供方失效。

## 验证范围

Windows、Linux、macOS 的 CI、安全回归、端到端连接和普通账户辅助服务测试通过。本地 70 项测试通过。

系统重启后的完整安装验收、各平台实际升级、公网性能和 OpenWrt 真机测试尚未完成；中英文仍有部分底层错误使用英文。校验和用于完整性验证，不代表独立发布签名。
