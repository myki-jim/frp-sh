# v0.5.5

- Add current-account `status` / `status --json` over access-controlled local IPC, with bounded responses and explicit unverified/error states.
- Add experimental `agent configure/run/start/stop` for headless supervision of existing profiles, persisted desired state, restart backoff and worker cleanup when its supervisor exits. Credentials are not copied into job files or command arguments.
- Synchronize Chinese and English CLI documentation and release limitations.
- Add internal foundations for device proofs, invitation tickets and persistent spaces. These are not connected to product APIs in this release.

## Scope and compatibility

This release does **not** install client/server OS services or enable unattended boot startup. `agent run` must remain running. Permanent spaces and 15-minute dynamic invitations are not yet available; existing room expiration and invitation behavior remain unchanged. Supervisor `joining` does not establish data-plane connectivity.

Signaling protocol v3 and network-helper protocol v2 remain unchanged. Existing 0.5.4 servers remain protocol-compatible. Re-run the installer to update client/helper; server binaries are deployed separately.
